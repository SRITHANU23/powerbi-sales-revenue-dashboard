# Power BI Sales & Revenue Dashboard
## 📊 Project Overview
This project is an interactive Power BI dashboard created to analyze sales and revenue performance.
The dashboard provides insights into revenue, transactions, regions, countries, stores, products, sales representatives, quarters, and monthly performance.
## 🎯 Objectives
- Analyze total and average revenue
- Track total transactions
- Compare revenue across regions and countries
- Analyze store-wise performance
- Understand product-wise revenue
- Compare quarterly sales performance
- Analyze monthly revenue trends
- Identify sales representative performance
## 🛠️ Tools & Technologies
- Power BI
- Microsoft Excel
- Data Cleaning
- Data Visualization
- Data Analysis
- DAX
## 📈 Dashboard Highlights
The dashboard includes:
- Total Revenue
- Average Revenue
- Total Countries
- Total Transactions
- Revenue by Region
- Revenue by Country and Region
- Average Revenue by Store
- Revenue by Quarter
- Revenue by Product and Rank
- Monthly Revenue Analysis
- Sales Representative Performance
## 📊 Key Dashboard Metrics
- Total Revenue: 127.41M
- Average Revenue: 39.04K
- Total Countries: 3264
- Total Transactions: 3264
## 🔍 Analysis Performed
The dashboard allows users to analyze sales performance using filters such as:
- Year
- Quarter
- Store Rank
This helps in understanding revenue trends and comparing business performance across different categories.
